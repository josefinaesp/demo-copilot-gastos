# Divisor de gastos

Proyecto de demo para la presentación de GitHub Copilot. Calcula cuánto debe o le deben a cada persona después de una salida en grupo.

## Setup

1. `npm install`
2. `npm run dev` para ver la app en el navegador
3. `npm run test` para correr los tests
4. `npm run lint` para revisar el código con ESLint
